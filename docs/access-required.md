# Необходимые учебные подключения

Личные и основные рабочие аккаунты не используются. Пароли и токены в Git и чат не передаются.

| Ресурс | Что необходимо | Состояние до подключения |
|---|---|---|
| GitHub | Подтвердить точный owner/repo учебного проекта, разрешить Pages / Actions | Проверен учебный владелец lastuser55556; репозиторий требует уточнения |
| GA4 | Отдельный учебный ресурс «КОЛЕСО 21 — сайт», Editor для настройки; публичный Measurement ID | BLOCKED: ID и учебный ресурс не предоставлены |
| Google Sheets | Учебная таблица «Koleso21 — Bookings» и связанный Apps Script, права редактора | BLOCKED: учебная таблица не подключена |
| Apps Script | Публикация Web app от учебного владельца, доступ «Anyone», URL /exec | Код подготовлен; живой приём не подтверждён |
| DataLens | Учебный workbook и подключение Google Sheets, доступ редактора | BLOCKED: ресурс не подключён |
| Instagram / ManyChat | Проектный профессиональный Instagram, ManyChat, тестовый аккаунт и выбранный Reel | BLOCKED: не подключены; Live и публикация требуют отдельного подтверждения |
| Соцсети | Отдельные проектные страницы Instagram, VK, Telegram, YouTube; подтверждение конкретных публикаций | Подготовить материалы можно локально; публикации запрещены без подтверждения |
| Партнёры | Ники двух студентов и ссылки на их согласованные размещения | Не заменять вымышленными опубликованными ссылками |
| Заказчик | Реальный учебный e-mail преподавателя для Viewer GA4 / Sheets / DataLens | Адрес admin@koleso21.example из ТЗ вымышленный |

Перед подключением браузерной сессии проверьте в профиле, что открыт учебный аккаунт. При запросе входа пользователь выполняет безопасную авторизацию самостоятельно. Если аккаунт основной, остановить настройку этого сервиса, продолжить независимую работу.
