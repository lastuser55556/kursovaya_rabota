## Подготовка данных

Нативная Google Sheets уже создана, четыре листа импортированы из проверенного XLSX по явно согласованному альтернативному процессу; схема и проверки данных подготовлены. Листы ga4_traffic и ga4_leads заполнять только реальными выгрузками GA4, а не числовыми примерами. GA4 уже создан и настроен, но DebugView пока 0 received; реальных выгрузок аналитики ещё нет. Apps Script авторизован и опубликован; контрольная заявка с Pages получена в строке 3, но GA4 received пока не подтверждён. Удалить служебные строки и «Общий итог». Схемы CSV лежат в reports/*.schema.csv; они пусты и не являются выгрузками. На уровне даты использовать один часовой пояс Europe/Moscow. Нормализовать (direct)→direct, (none)→none, (not set)→not_set; пустой источник direct. Не переименовывать реальные источники произвольно.

Для отчётов подготовить безопасную проекцию leads: request_id, created_at, car_type, rim_size, slot, utm_source, utm_medium, utm_campaign, utm_content, status. name/phone/email исключить из датасета и tooltip. Не публиковать исходный лист с контактами.

## Трафик

Источники ga4_traffic и ga4_leads. Индикаторы Sessions, Active users, generate_lead. Линия Sessions по date; таблица source/medium/campaign. Закреплённые селекторы периода и источника связать со всеми виджетами. Active users нельзя безусловно суммировать по дням/кампаниям: пользователь может встречаться в нескольких строках. Для KPI за период использовать отдельную дедуплицированную выгрузку GA4 на нужном scope, документировать уровень агрегации.

## Заявки

Из leads: Всего COUNTD(request_id), Новые COUNTD_IF(request_id,status='new'), Клиент приехал COUNTD_IF(request_id,status='visited'). Если конкретный редактор не поддерживает COUNTD_IF, эквивалент COUNTD(IF(status='visited',request_id,NULL)). Столбцы по status, заявки по источникам и дням. Общие selectors period и status. Период по created_at, а не дате визита, если отдельно не подписано иначе.

## Кампании

Сначала агрегировать каждый из трёх источников до уникального ключа date/source/campaign. Затем соединять только по этим трём полям; полный набор ключей взять объединением ключей всех источников, чтобы не потерять заявки без GA4. Не соединять сырые leads с сырым traffic: это размножит Sessions и заявки. В таблице Sessions, generate_lead, bookings, visited. Не суммировать Active users в этой вкладке.

Формула в аналитической записке: заявок на 100 сеансов = bookings / sessions ×100; если sessions=0, результат «не определён». Это соотношение систем, а не гарантированная пользовательская конверсия.
