## Протокол одной проверки

Записать дату/время (с часовым поясом), commit SHA, URL, браузер/ширину, исполнителя, шаги, ожидаемый и фактический результат, путь к реальному доказательству, PASS/FAIL/BLOCKED. Скриншоты PII скрывать перед публичным GitHub. Для И-03 записать request_id и время получения. Для И-05 повторить именно тот же ID через приёмник, а не только кнопку клиента. Моки допускаются как дополнительное тестирование кода с явной пометкой mock.

## Акт заказчика

ФИО исполнителя/группа, дата выдачи, реальный email заказчика, оценка, подписи и штамп остаются незаполненными до предоставления данных и приёмки. После замечаний ТЗ предусматривает одно исправление в течение 3 дней и повтор только непройденных испытаний. Самостоятельно оценку не выставлять.
